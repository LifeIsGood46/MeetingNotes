MeetingNotes turns recordings into documents

Drop in a meeting video, get back a transcript, notes, actions or a test plan — all on your own machine.

It works in four passes

Extract audio, transcribe with Whisper, fix domain terms, then polish with an LLM. Each file is a card you can track.

Get set up in three steps

1. Settings → download a model. 2. Drop a recording, pick a profile, press Start. 3. Add an LLM key only if you want formatted docs.

Where everything lives

Models in models/, finished docs in results/<name>/, app state in data/, temp uploads in data/work/. Delete the app folder and it’s all gone.
